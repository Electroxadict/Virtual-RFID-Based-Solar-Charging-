# Virtual-RFID-Based-Solar-Charging-
Virtual RFID Based Solar Charging is a Flask-based smart EV charging simulation with RFID authentication, wallet recharge, and charging management. It features a futuristic UI and demonstrates virtual renewable energy charging concepts without physical hardware
# Installation

## Clone the Repository
git clone https://github.com/Electroxadict/Virtual-RFID-Based-Solar-Charging-.git

## Go to Project Folder
cd Virtual-RFID-Based-Solar-Charging-

## Install Dependencies
pip install flask

## Required Python Modules
- Flask
- time (built-in)
- jsonify
- request
- render_template_string

## Run the Project
python app.py

## Open in Browser
http://127.0.0.1:5000

# ⚡ Virtual RFID Based Solar Charging

A futuristic Flask-based smart EV charging simulation system that uses virtual RFID authentication, wallet recharge, and charging balance management without physical hardware. The project demonstrates renewable energy charging concepts with an interactive cyberpunk-inspired UI.

---

# 🚀 Features

- Virtual RFID Card Authentication
- Smart EV Charging Simulation
- Rechargeable Digital Wallet
- Real-Time Balance Management
- Interactive Futuristic UI
- Charging Cost Calculation
- Activity Log System
- RFID Scan Animation
- Multi-User Simulation
- Flask Backend Integration
- Responsive Design
